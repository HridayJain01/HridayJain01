I'm a full-stack engineer who likes taking an idea all the way to a deployed product: data model, API, UI, and the boring-but-important parts like auth, tests and backups.

Most of my work is **TypeScript + React on the front, Node/Express or Spring Boot on the back**, with MongoDB, MySQL or Postgres underneath. Lately I've been building with **LLMs and on-device AI**, where the model interprets and plain, tested code does the actual math.

I've shipped production sites for real clients, a microservice banking platform, and a few apps my friends use every week.

## Selected work

| Project | What it is | Built with |
|---|---|---|
| **[MoneyBags](https://github.com/HridayJain01/MoneyBagAI)** | Core-banking platform: 14 Spring Boot microservices behind one API gateway, 12 MySQL schemas with Flyway migrations, JWT + permission-based auth | Java · Spring Boot · MySQL |
| **[Self-Healing ELT](https://github.com/HridayJain01/self-healing-elt)** | Agentic data pipeline that detects, diagnoses and fixes its own failures (schema drift, bad data), then learns local rules so the next fix skips the LLM | Python · Gemini |
| **[DeArte](https://github.com/HridayJain01/dearte)** · [live](https://dearte-client.vercel.app) | B2B jewellery commerce platform with buyer storefront and admin dashboard, cookie-based auth, rate limiting, Cloudinary media | React · Express · MongoDB |
| **[Crumb](https://github.com/HridayJain01/Crumb)** | Health journal PWA (Google AI hackathon): log meals by photo, voice or text, honest ranges instead of fake precision, offline fallback parser | TypeScript · Gemini · Firebase · Cloud Run |
| **[Star Learners Library](https://github.com/HridayJain01/SLL_Dev)** · [live](https://sll-dev-client.vercel.app) | Management system for a study library, built for a real client | TypeScript · React · Node |
| **[Drive Ease](https://github.com/HridayJain01/DriveEase)** · [live](https://drive-ease-kappa.vercel.app) | Car-rental site with a full CMS (cars, enquiries pipeline, blog, reviews) and WhatsApp lead flow | React · Express · MongoDB |
